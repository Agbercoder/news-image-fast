Sum up Tuesday 24 November 2026's world news in one image — a newspaper front
page. Lead story: Ukraine says its naval drones sank the Russian corvette
Merkury at Benghazi, Libya. Also: the COP31 climate talks collapse in Antalya,
Russia probes NATO skies, tankers burn in the Strait of Hormuz, and Nvidia
rehires Jensen Huang.

The entry is a program (`main.ts`, Node 22, standard library only) that copies
the front page (`entry.png`, 1024×1024) to `/output/entry.png`. No network, no
randomness: two runs write the same bytes.
